# 1.2.4

- The `missing_nutrients` and `missing_food` options in the `logging` section of `nutritional-server.toml` now work. Before this they did nothing. Turn them on and they write to `latest.log` when the server starts and after every `/reload`:
  - `missing_nutrients` lists every edible item that isn't in any nutrient tag.
  - `missing_food` lists items in nutrient or food hint tags that don't exist even though their mod is installed, which usually means the mod renamed or removed them.
- New operator command `/nutritional-food unmapped` lists every food with no nutrients in chat. Add a mod id, like `/nutritional-food unmapped farmersdelight`, to see only that mod's foods. Chat shows the first 50 and the full list goes to the server log.
